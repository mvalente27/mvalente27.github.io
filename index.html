Live-or-Die Bot

Autonomous crypto trading bot powered by Q-Learning reinforcement learning. Makes real-time buy / sell / hold decisions on Bitcoin using live CoinGecko prices, ACD (Mark Fisher) signal context, and an Interactive Brokers paper-trading execution path. The agent's Q-table persists across sessions so it keeps improving with every run.

  • Q-Learning agent with epsilon-greedy exploration and persistent Q-table
  • ACD strategy engine — A/C levels, opening range, and directional signals
  • Interactive Brokers (TWS / Gateway) integration for multi-asset paper execution
  • State discretization over live price, balance, and position data
