Live-or-Die Bot — IBKR Futures Trading System

Autonomous algorithmic futures trading bot connected to Interactive Brokers (TWS/Gateway) via ib_insync. A Double DQN agent with Dueling architecture makes real-time buy / sell / hold decisions across NQ, MNQ, YM, MYM, CL, GC, and Bitcoin futures using a 14-dimension state vector updated every 60 seconds.

  • Double DQN (Dueling network) with soft Polyak target update (τ=0.005), prioritized replay, Huber loss, and gradient clipping
  • Indicator stack: Mark Fisher ACD (opening range + A/C levels), Elliott Wave v2 (rule-enforced W2/W3/W4 + Fibonacci targets), Williams Alligator, ADX, VWAP, and market regime classifier
  • Reward engine blends normalised PnL, rolling Sharpe ratio, quadratic drawdown penalty, and a confluence bonus when ACD + Elliott + Alligator signals agree
  • Risk controls: daily loss circuit breaker, rolling drawdown gate, Kelly / proportional account-aware position sizing, auto-tier contract resolution (Micro vs Full) by account equity

Q-Signals — AI-Powered Market Sentiment Research Platform

Algorithmic sentiment research platform that rates stocks and futures as bullish, bearish, or neutral using 41 analysis modules and a DQN reinforcement learning agent (18K parameters). A Dual-Gate Consensus requires composite score ≥ ±0.10 AND 60% module agreement before any sentiment rating is published. Live at q-signals.com with an Android app on Google Play.

  • 41 modules spanning Elliott Wave, Fibonacci, 61 TA-Lib candlestick patterns, SEC EDGAR insider / institutional filings, FRED macro data, Reddit / StockTwits sentiment, and earnings surprise
  • DQN agent evaluates sentiment accuracy against T1/T2/T3 ATR-scaled price targets across 24h / 2wk / 3mo horizons; module weights adapt dynamically by hit rate
  • FastAPI server (api.q-signals.com) with rate limiting, API key auth, CORS hardening; Supabase persistence for sentiment history and model state
  • Android War Room app via Capacitor 6; Stripe subscription billing; static site on Cloudflare Pages

DFS AI Agent — DraftKings Lineup Optimizer

Daily Fantasy Sports lineup optimizer for DraftKings using a three-model ML ensemble and an OR-Tools constraint solver. Computes a 20-metric feature vector per player, simulates 10,000+ crowd lineups, and applies Kelly Criterion bankroll management.

  • ML ensemble: LightGBM + XGBoost + PyTorch neural net (3×128, ReLU, dropout) blended by inverse-MAE adaptive weighting per sport and contest type
  • OR-Tools constraint solver: $50K salary cap, 60% max player exposure, cosine uniqueness ≥ 0.35, position-specific rules for NFL / NBA / MLB
  • 20-metric pipeline: Vegas totals, pace, ownership leverage, social sentiment velocity, salary inefficiency, field simulation, Kelly edge contribution
  • Walk-forward backtester with 2-season lookback and 30-day rolling validation windows; FastAPI server + Typer CLI
